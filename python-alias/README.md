# clickruntime

This package installs the ClickRuntime CLI, published as [`clickruntime-cli`](https://pypi.org/project/clickruntime-cli/). Either name gives you the same `clickruntime` command.

```bash
pipx install clickruntime-cli
```

ClickRuntime runs Python automations on a schedule or when an event arrives at a trigger link. Coding assistants such as Claude Code, Codex and Cursor use the CLI to save, deploy and run them, and you approve each step.

- CLI: https://clickruntime.com/cli
- CLI docs: https://clickruntime.com/docs/cli
- API docs: https://clickruntime.com/docs/api
- Source: https://github.com/ClickRuntime/cli
